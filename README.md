# Heart Disease Risk Analysis – Excel | SQL | Power BI

A complete **Data Analytics project** focused on analyzing heart disease patient data using **Excel, SQL, and Power BI**.

The project covers the complete analytics workflow — from **data cleaning and preparation to SQL-based analysis and interactive Power BI dashboard development**.

---

## Project Overview

The objective of this project is to analyze patient health data and identify meaningful patterns across different demographic and clinical indicators.

The analysis focuses on factors such as:

* Age
* Gender
* Cholesterol
* Blood Pressure
* Maximum Heart Rate
* Chest Pain
* Other patient health indicators

The final Power BI dashboard converts the analyzed data into interactive visual insights and KPI-driven reports.

Key activities included:

* Analyzing clinical indicators

## Power BI Dashboard

The analyzed data was used to create an interactive **Power BI dashboard**.

### Key Metrics

The dashboard provides analysis of metrics such as:

* Total Patients
* Average Age
* Average Cholesterol
* Average Blood Pressure
* Maximum Heart Rate

### Patient Analysis

The dashboard allows analysis based on:

* Gender
* Age Groups
* Chest Pain Categories
* Clinical Indicators

### Interactive Analysis

Users can interact with the dashboard using filters and slicers to explore different patient segments and identify patterns within the dataset.
